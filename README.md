Что это такое и как этим пользоваться? 


Это бот с Админ панелью, который уведомляет админа каждый раз когда кто-то заходит на fastapi-ссылку и присылает данные, которые ввёл юзер в path(то что после /) query параметрах(после ?) 

http://localhost:8000/name/{username}?age={age}

вот пример ссылки. 


Команды Бота:
/start - запустить Бота
/AllShow - показать всех юзеров, которые когда-либо заходили по ссылке
/Search_name {name} - найти информацию по имени. 
пример:
/Search_name Alex

технологии проекта:
•Aiogram ( для работы с ботом в телеграмм) 
•Fastapi ( API и ссылка) 
•Асинхронная бд aiosqlite ( для хранения информации) 
•Dotenv ( Для скрытия API токена)
